# Windows appliance image build

Builds the sealed Ubuntu 24.04 ProjectAchilles VM image. Packer, QEMU, OVMF and
libguestfs all run inside one builder container, so local and CI builds use
identical tools.

## Prerequisites

- Docker, able to run containers with `--device /dev/kvm`
- `/dev/kvm` on the host (hardware virtualisation)
- Go (host) for the installer binaries
- At least 40 GB free in `appliance/out/`

No qemu, packer or libguestfs is needed on the host.

## Targets

Run from the repo root with `make -C appliance <target>`.

| Target | What it does |
|--------|--------------|
| `builder` | Build the `achilles-appliance-builder:local` image (about 5 min first time) |
| `builder-smoke` | Check packer, qemu, OVMF, `/dev/kvm` and libguestfs in the container |
| `check-space` | Fail unless 40 GB are free in `appliance/out` |
| `base-image` | Download the Ubuntu 24.04 cloud image, verify against `SHA256SUMS` (about 600 MB) |
| `installer-bin` | Build `out/achilles-installer` (host Go) |
| `installer-testbin` | Build `out/achilles-installer-test` (`-tags appliancetest`) |
| `out-ownership-check` | Prove container targets leave `out/` owned by you (`DOCKER_RUN_OUT`) |
| `image` | Build `out/achilles-appliance-<ver>.qcow2` with Packer from the committed HEAD (refuses a dirty tree; about 6-10 min with KVM). Log: `out/packer.log`, VM console: `out/serial.log` |
| `check-sealed` | Assert the image is sealed (`IMAGE=` defaults to this `VER`'s image) |
| `boot-test` | Boot `IMAGE` in two throwaway UEFI VMs (`test/boot-test.sh`). `MODE=quick` (about 10 min): first boot, distinct identities, clean checkout and image labels at the build commit, reboot. `MODE=full` (10-40 min) also installs on VM1, backs it up and restores the backup on VM2. Serial logs and install output: `out/boot-test/` |
| `vhdx` | Produce the Hyper-V zip (later task) |
| `clean` | Remove `appliance/out/` |

`VER` defaults to `git describe --tags --always --dirty`; override with
`make VER=x.y.z ...`.

## Disk use

`out/` needs about 40 GB at peak: base image (about 600 MB), the 80 GB sparse
qcow2 (a few GB real), and the converted VHDX. Full build time is roughly
20-40 minutes with KVM.

## How `image` works

`appliance.pkr.hcl` boots the Ubuntu cloud image under KVM/OVMF with a
cloud-init seed that creates the `achilles` build user (per-build random
password, generated by `build/build-image.sh`, never written to a file).
The provisioners run in order:

| Script | Does |
|--------|------|
| `provision/10-base.sh` | apt upgrade, guest tools, console/keyboard packages, security-only unattended upgrades, UTC |
| `provision/20-docker.sh` | Docker CE + compose plugin from Docker's apt repo (key fingerprint checked) |
| `provision/30-repo.sh` | `/opt/projectachilles` from `out/repo.bundle`, `origin` = GitHub, detached at the build commit; the installer binary + `/usr/local/bin` symlink |
| `provision/40-images.sh` | builds `achilles-server-backend`/`-frontend` (label `io.projectachilles.commit`) and pulls the other compose images; never starts the stack |
| `provision/50-rootfs.sh` | copies `rootfs/` to `/`, hands the network to `50-achilles.yaml`, disables cloud-init, enables the achilles units, disables getty@tty1 and ssh |
| `seal.sh` | removes identity, credentials, logs and build leftovers; the steps that take sudo away run at shutdown from a transient unit |

The image holds the committed HEAD, so commit first: `image` refuses a
`-dirty` version. `build-image.sh` sparsifies the qcow2, refuses it if it
contains the build password or its hash, and runs `check-sealed` before the
qcow2 gets its final name; `make check-sealed` re-runs the gate.
